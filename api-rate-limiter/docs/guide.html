1. Overview

A production-ready API rate limiting service with Redis-backed sliding window, IP and API key tracking, customizable limits per endpoint, real-time analytics dashboard, and webhook alerts. Drop it in front of any API to prevent abuse.

Tech Stack

Python FastAPI Docker

Features

  • Sliding window rate limiting algorithm
  • Per-IP and per-API-key tracking
  • Customizable limits per endpoint
  • Real-time analytics dashboard
  • Redis-backed for high performance
  • Webhook alerts on limit breaches
  • Docker-ready deployment
  • FastAPI middleware — drop into any project

2. Quick Start

1

Extract the package

tar -xzf api-rate-limiter.tar.gz
cd api-rate-limiter/
2

Configure environment

cp .env.example .env
# Edit .env with your API keys
nano .env
3

Run setup

chmod +x setup.sh
./setup.sh
4

Verify

curl http://localhost:8000/
# Interactive docs: http://localhost:8000/docs
💡 Tip: Open http://localhost:8000/docs for the interactive Swagger UI.

4. API Reference

GET /

Service info and health check.

curl -X GET http://localhost:8000/ \
  -H "Content-Type: application/json"
GET /health

Health check endpoint.

curl -X GET http://localhost:8000/health \
  -H "Content-Type: application/json"
POST /check

Check if a request should be allowed (without consuming a token).

curl -X POST http://localhost:8000/check \
  -H "Content-Type: application/json"
POST /hit

Record a request hit and return rate limit status.

curl -X POST http://localhost:8000/hit \
  -H "Content-Type: application/json"
GET /rules

List all custom rate limit rules.

curl -X GET http://localhost:8000/rules \
  -H "Content-Type: application/json"
POST /rules

Create or update a rate limit rule for an endpoint.

curl -X POST http://localhost:8000/rules \
  -H "Content-Type: application/json"
DELETE /rules/{endpoint:path}

Delete a rate limit rule.

curl -X DELETE http://localhost:8000/rules/{endpoint:path} \
  -H "Content-Type: application/json"
GET /clients

List all tracked clients with their current usage.

curl -X GET http://localhost:8000/clients \
  -H "Content-Type: application/json"
GET /clients/{client_id}

Get detailed stats for a specific client.

curl -X GET http://localhost:8000/clients/{client_id} \
  -H "Content-Type: application/json"
DELETE /clients/{client_id}

Reset rate limit counters for a client.

curl -X DELETE http://localhost:8000/clients/{client_id} \
  -H "Content-Type: application/json"
GET /analytics

Get global analytics and usage statistics.

curl -X GET http://localhost:8000/analytics \
  -H "Content-Type: application/json"
GET /dashboard

Real-time analytics dashboard.

curl -X GET http://localhost:8000/dashboard \
  -H "Content-Type: application/json"

5. Docker Deployment

1

Build

docker build -t api-rate-limiter .
2

Run

docker run -d --name api-rate-limiter --env-file .env -p 8000:8000 api-rate-limiter

6. Troubleshooting

⚠️ "Module not found": Run ./setup.sh or pip install -r requirements.txt
⚠️ "API key not set": Check your .env file
⚠️ Port in use: Change PORT in .env or run lsof -i :8000
