2. Quick Start

1

Extract the package

tar -xzf ai-seo-content-generator.tar.gz
cd ai-seo-content-generator/
2

Configure environment

cp .env.example .env
# Edit .env with your API keys
nano .env
3

Run setup

chmod +x setup.sh
./setup.sh
4

Verify

curl http://localhost:8000/
# Interactive docs: http://localhost:8000/docs
💡 Tip: Open http://localhost:8000/docs for the interactive Swagger UI.

4. API Reference

GET /health

Health check endpoint

curl -X GET http://localhost:8000/health \
  -H "Content-Type: application/json"
POST /generate/blog-post

Generate SEO-optimized blog post

curl -X POST http://localhost:8000/generate/blog-post \
  -H "Content-Type: application/json"
POST /generate/meta-description

Generate SEO-optimized meta description

curl -X POST http://localhost:8000/generate/meta-description \
  -H "Content-Type: application/json"
POST /analyze/keywords

Analyze keyword difficulty and opportunities

curl -X POST http://localhost:8000/analyze/keywords \
  -H "Content-Type: application/json"
POST /analyze/competitors

Analyze competitor content and find opportunities

curl -X POST http://localhost:8000/analyze/competitors \
  -H "Content-Type: application/json"
GET /stats

Get service statistics

curl -X GET http://localhost:8000/stats \
  -H "Content-Type: application/json"

5. Docker Deployment

1

Build

docker build -t ai-seo-content-generator .
2

Run

docker run -d --name ai-seo-content-generator --env-file .env -p 8000:8000 ai-seo-content-generator

6. Troubleshooting

⚠️ "Module not found": Run ./setup.sh or pip install -r requirements.txt
⚠️ "API key not set": Check your .env file
⚠️ Port in use: Change PORT in .env or run lsof -i :8000
