2. Quick Start

1

Extract the package

tar -xzf appointment-booking-system.tar.gz
cd appointment-booking-system/
2

Configure environment

cp .env.example .env
# Edit .env with your API keys
nano .env
3

Run setup

chmod +x setup.sh
./setup.sh
4

Verify

curl http://localhost:8000/
# Interactive docs: http://localhost:8000/docs
💡 Tip: Open http://localhost:8000/docs for the interactive Swagger UI.

4. API Reference

GET /health

Health check endpoint

curl -X GET http://localhost:8000/health \
  -H "Content-Type: application/json"
POST /bookings

Create a new appointment booking

curl -X POST http://localhost:8000/bookings \
  -H "Content-Type: application/json"
GET /bookings

Create a new time slot

curl -X GET http://localhost:8000/bookings \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ADMIN_API_KEY"
GET /availability

Create a new time slot

curl -X GET http://localhost:8000/availability \
  -H "Content-Type: application/json"
POST /slots

Create a new time slot

curl -X POST http://localhost:8000/slots \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ADMIN_API_KEY"
DELETE /bookings/{booking_id}

Cancel a booking

curl -X DELETE http://localhost:8000/bookings/{booking_id} \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ADMIN_API_KEY"
PUT /bookings/{booking_id}

Update an existing booking

curl -X PUT http://localhost:8000/bookings/{booking_id} \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ADMIN_API_KEY"
GET /stats

Get booking statistics

curl -X GET http://localhost:8000/stats \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ADMIN_API_KEY"

5. Docker Deployment

1

Build

docker build -t appointment-booking-system .
2

Run

docker run -d --name appointment-booking-system --env-file .env -p 8000:8000 appointment-booking-system

6. Troubleshooting

⚠️ "Module not found": Run ./setup.sh or pip install -r requirements.txt
⚠️ "API key not set": Check your .env file
⚠️ Port in use: Change PORT in .env or run lsof -i :8000
