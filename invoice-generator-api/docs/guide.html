2. Quick Start

1

Extract the package

tar -xzf invoice-generator-api.tar.gz
cd invoice-generator-api/
2

Configure environment

cp .env.example .env
# Edit .env with your API keys
nano .env
3

Run setup

chmod +x setup.sh
./setup.sh
4

Verify

curl http://localhost:8000/
# Interactive docs: http://localhost:8000/docs
💡 Tip: Open http://localhost:8000/docs for the interactive Swagger UI.

4. API Reference

GET /

Health check endpoint.

curl -X GET http://localhost:8000/ \
  -H "Content-Type: application/json"
POST /invoices

Create a new invoice.

curl -X POST http://localhost:8000/invoices \
  -H "Content-Type: application/json"
GET /invoices/{invoice_id}

Get a specific invoice by ID.

curl -X GET http://localhost:8000/invoices/{invoice_id} \
  -H "Content-Type: application/json"
GET /invoices/{invoice_id}/pdf

Generate and return invoice as PDF.

curl -X GET http://localhost:8000/invoices/{invoice_id}/pdf \
  -H "Content-Type: application/json"
GET /invoices/{invoice_id}/html

Get invoice as HTML (useful for preview or fallback).

curl -X GET http://localhost:8000/invoices/{invoice_id}/html \
  -H "Content-Type: application/json"
GET /invoices

List invoices with optional filtering.

curl -X GET http://localhost:8000/invoices \
  -H "Content-Type: application/json"
PUT /invoices/{invoice_id}

Update an existing invoice.

curl -X PUT http://localhost:8000/invoices/{invoice_id} \
  -H "Content-Type: application/json"
DELETE /invoices/{invoice_id}

Delete an invoice.

curl -X DELETE http://localhost:8000/invoices/{invoice_id} \
  -H "Content-Type: application/json"

6. Troubleshooting

⚠️ "Module not found": Run ./setup.sh or pip install -r requirements.txt
⚠️ "API key not set": Check your .env file
⚠️ Port in use: Change PORT in .env or run lsof -i :8000
