2. Quick Start

1

Extract the package

tar -xzf ai-customer-support-bot.tar.gz
cd ai-customer-support-bot/
2

Configure environment

cp .env.example .env
# Edit .env with your API keys
nano .env
3

Run setup

chmod +x setup.sh
./setup.sh
4

Verify

curl http://localhost:8000/
# Interactive docs: http://localhost:8000/docs
💡 Tip: Open http://localhost:8000/docs for the interactive Swagger UI.

4. API Reference

GET /

Health check endpoint.

curl -X GET http://localhost:8000/ \
  -H "Content-Type: application/json"
POST /chat

Handle chat messages and generate AI responses.

curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $API_KEY"
GET /conversations

Get list of conversations.

curl -X GET http://localhost:8000/conversations \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $API_KEY"
GET /conversations/{conversation_id}

Get detailed conversation with all messages.

curl -X GET http://localhost:8000/conversations/{conversation_id} \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $API_KEY"
POST /feedback

Submit feedback for conversation or specific message.

curl -X POST http://localhost:8000/feedback \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $API_KEY"
GET /analytics

Get basic analytics about the support bot.

curl -X GET http://localhost:8000/analytics \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $API_KEY"

5. Docker Deployment

1

Build

docker build -t ai-customer-support-bot .
2

Run

docker run -d --name ai-customer-support-bot --env-file .env -p 8000:8000 ai-customer-support-bot

6. Troubleshooting

⚠️ "Module not found": Run ./setup.sh or pip install -r requirements.txt
⚠️ "API key not set": Check your .env file
⚠️ Port in use: Change PORT in .env or run lsof -i :8000
