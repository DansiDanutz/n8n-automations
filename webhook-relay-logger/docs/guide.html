1. Overview

Catch, inspect, forward, and replay webhooks with advanced debugging capabilities. Perfect for integration testing and webhook development.

Tech Stack

Python FastAPI SQLAlchemy Redis Celery Docker

Features

  • Universal webhook catcher for any HTTP method
  • Real-time webhook inspection and logging
  • Advanced filtering and search capabilities
  • Webhook relay and forwarding rules
  • Payload transformation and modification
  • Webhook replay functionality
  • Web dashboard for easy debugging
  • Analytics and performance monitoring
  • Rate limiting and authentication
  • Export webhook data for analysis

2. Quick Start

1

Extract the package

tar -xzf webhook-relay-logger.tar.gz
cd webhook-relay-logger/
2

Configure environment

cp .env.example .env
# Edit .env with your API keys
nano .env
3

Run setup

chmod +x setup.sh
./setup.sh
4

Verify

curl http://localhost:8000/
# Interactive docs: http://localhost:8000/docs
💡 Tip: Open http://localhost:8000/docs for the interactive Swagger UI.

6. Troubleshooting

⚠️ "Module not found": Run ./setup.sh or pip install -r requirements.txt
⚠️ "API key not set": Check your .env file
⚠️ Port in use: Change PORT in .env or run lsof -i :8000
